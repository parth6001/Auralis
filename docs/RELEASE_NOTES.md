# Auralis 0.1.0 (development preview)

Native local music player with read-only folder scanning, Room library, Media3 foreground playback/session, saved paused queue, library grouping/search/favourites, editable queues and playlists, generated smart mixes, explainable recommendations, privacy reset/exclusions, local JSON portability, output diagnostics and IEM profile controls.

Home, Library, Smart Mixes, Equalizer and Search adapt to phone/tablet widths. Includes Light, Dark, AMOLED and System themes, system-bar appearance, embedded artwork display, local lyric text, labelled playback actions and system motion preferences.

This preview includes generated test fixtures and automated test sources. It has no Internet permission or tracking SDK. Physical USB behavior and several advanced audio/product features remain unverified or unimplemented; see KNOWN_LIMITATIONS.md. Signed production release requires the owner's key and physical-device validation. Artifact version, size and checksums are generated in artifacts/APK_REPORT.md and SHA256SUMS.txt.
